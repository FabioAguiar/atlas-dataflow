# Design Prototype Behavior Inventory

M41-02 classifies the executable JavaScript behavior in the current
support-root design prototypes before downstream React translation. The
prototype scripts are UX behavior references only. They are not production code,
not API contracts, not schema authority, and not publisher/runtime truth.

This inventory does not authorize runtime code changes. React paths are owner
surfaces for downstream planning. Schema and API references are dependency
checks, not edit authorization.

## Classification Taxonomy

| Classification | Meaning |
| --- | --- |
| `already implemented` | Current React already has an equivalent behavior within the relevant product boundary. |
| `implementable in React` | Behavior is local UI state that can be translated to React without new backend or schema ownership. |
| `schema/API-backed` | Behavior depends on an existing schema or API contract and must stay within that contract. |
| `preview-only` | Behavior may update a local/private preview but must not imply real prediction, publishing, upload, or backend mutation. |
| `disabled` | The UI may represent the behavior as unavailable because no safe owner exists. |
| `deferred` | The behavior needs a later M42 through M45 implementation or explicit schema/API reconciliation. |
